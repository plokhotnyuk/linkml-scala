## Inherited fields

A type implements the interfaces of its parent classes and mixins. An interface leaves out a field when a descendant changes it in a way that GraphQL doesn't allow, such as a `slot_usage` that renames the field with an alias. Each type still has all its fields. See [Slots changed by a class](/docs/slot-usage-inheritance/#slots-changed-by-a-class).
